# Later-phase platform conventions

From the Insper reference, with Carmonai overrides applied. Follow it when each piece arrives — **observability is built** ([observability.md](observability.md)); the rest is not.

- **Edge**: nginx in front of gateway replicas — `upstream gateways { server gateway:8080; }`, round-robin by default (`least_conn` when request cost varies). Replicas come from compose `deploy.replicas` or K8s; the gateway stays stateless.
- **Cache (Redis)**: `spring-boot-starter-data-redis` + `starter-cache`, `@EnableCaching`, `@Cacheable(value="accounts", key="#id")`, `@CacheEvict` on writes. Default TTL 5 min, `cache-null-values: false`. Cached personal data carries a TTL and is evicted on erasure.
- **Messaging (Kafka)**: `spring-kafka`; producer `acks=all`, `enable.idempotence=true`, JSON values, string keys. Topics `<domain>-events` + `<domain>-events-dlq`; consumers idempotent with manual commit and one group per consumer. Use KRaft (the reference compose uses ZooKeeper); create topics explicitly outside dev. Events carry ids, never personal data.
- **Observability**: logs as JSON on stdout with `trace_id`/`span_id`; traces via the OpenTelemetry Java agent in the image (`OTEL_SERVICE_NAME`, `OTEL_EXPORTER_OTLP_ENDPOINT`, `OTEL_PROPAGATORS=tracecontext,baggage`, sampler `parentbased_traceidratio` 0.1 in prod) — **not built**; metrics via `micrometer-registry-prometheus`, scraped on the management port every 15 s by Prometheus and drawn by Grafana (RED per service, one SLO dashboard), provisioned from `docker/` — built 2026-10-05, SLIs/SLOs and the gaps in [observability.md](observability.md); no Alertmanager yet, so alert rules and their firing state live in Prometheus and Grafana.
- **Kubernetes**: Deployment + ClusterIP Service + ConfigMap + Secret per component; requests/limits on every container (reference baseline 256Mi/250m requests, 512Mi/500m limits); liveness/readiness probes; HPA; secrets from a secret manager (K8s Secrets are only base64).
- **CI/CD**: reference uses Jenkins (declarative, `mvn -B clean install`, buildx push to Docker Hub, `withCredentials`). The tool is a pending decision. Run tests in CI (the reference passes `-DskipTests`) and tag images with the commit SHA.
